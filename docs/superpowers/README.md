# Historical Design And Implementation Records

ไฟล์ที่มีวันที่ใน specs/ และ plans/ เป็นบันทึกการออกแบบและแผนการทำงานในช่วงเวลานั้น ไม่ใช่คู่มือที่ใช้แทนสถานะโค้ดปัจจุบัน

- ใช้เพื่อสืบว่าเหตุใดจึงตัดสินใจทำ feature หนึ่ง
- ตรวจ source code, migration, tests และเอกสาร active ก่อนนำข้อกำหนดเก่ากลับมาใช้
- เมื่อแผนทำเสร็จ ให้เปลี่ยน status หรือ checklist ให้สะท้อนผลจริง
- เอกสาร active อยู่ที่ ../README.md, ../../README.md, ../../PRODUCT.md, ../../DESIGN.md และ ../../AGENTS.md
