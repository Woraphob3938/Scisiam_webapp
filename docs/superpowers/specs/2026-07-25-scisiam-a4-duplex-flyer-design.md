# สเปกการออกแบบใบปลิว SciSiam แบบ A4 หน้าและหลัง

วันที่จัดทำ: 25 กรกฎาคม 2569  
สถานะ: รอการอนุมัติก่อนสร้างไฟล์จริง

## 1. เป้าหมาย

จัดทำใบปลิวประชาสัมพันธ์ SciSiam สำหรับพิมพ์บนกระดาษ A4 แนวตั้งแบบหน้าและหลัง ให้ผู้รับเข้าใจประโยชน์ของแอปได้อย่างรวดเร็ว และเข้าถึงการติดตั้ง คู่มือการใช้งาน และเว็บไซต์ได้จาก QR Code 3 รายการ

กลุ่มผู้อ่านหลักคือกรรมการ นักเรียน และครู ภาพรวมต้องทันสมัย สบายตา เป็นมิตร และน่าเชื่อถือในฐานะแพลตฟอร์มการเรียนรู้วิทยาศาสตร์และคณิตศาสตร์

## 2. ขอบเขตงาน

### สิ่งที่จะจัดทำ

- ใบปลิว A4 แนวตั้ง 2 หน้า สำหรับพิมพ์หน้าและหลัง
- ไฟล์ Word ที่เปิดแก้ไขข้อความได้
- ไฟล์ PDF ความละเอียดสูงสำหรับพิมพ์
- ภาพตัวอย่าง PNG แยกด้านหน้าและด้านหลัง
- QR Code ใช้งานจริง 3 รายการ

### สิ่งที่อยู่นอกขอบเขต

- ไม่แก้ไขโค้ดหรือหน้าจอของแอป SciSiam
- ไม่แก้ไขคู่มือหรือรายงานเดิม
- ไม่เปลี่ยนโลโก้ สีประจำแบรนด์ หรือรูปลักษณ์ของน้องไออุ่น
- ไม่สร้างตัวเลขสถิติ คำรับรอง หรือข้อมูลที่ไม่มีแหล่งอ้างอิง

## 4. รูปแบบการพิมพ์

- ขนาดกระดาษ: A4 แนวตั้ง 210 × 297 มิลลิเมตร
- จำนวนหน้า: 2 หน้า
- การใช้งาน: พิมพ์หน้าและหลัง พลิกด้านตามขอบยาว
- พื้นที่ปลอดภัย: เนื้อหาสำคัญห่างจากขอบกระดาษอย่างน้อย 10 มิลลิเมตร
- ความละเอียดภาพ: อย่างน้อย 300 dpi สำหรับภาพที่ใช้พิมพ์
- สี: RGB ในไฟล์ Word และ PNG โดยตรวจให้สีอ่านได้ชัดเจนเมื่อพิมพ์ด้วยเครื่องพิมพ์สำนักงาน
- ไม่ใช้พื้นหลังเข้มเต็มหน้า เพื่อประหยัดหมึกและรักษาความสบายตา

- ตัวอักษรภาษาไทย: Noto Sans Thai
- ตัวอักษรภาษาอังกฤษ: Inter
- สีข้อความหลัก: `#0F172A`

## 6. ด้านหน้า

### โครงสร้าง

1. ส่วนหัววางโลโก้ SciSiam ทางซ้าย และข้อความ “Simulation Lab” ขนาดเล็กทางขวา
2. หัวเรื่องหลักอยู่ช่วงบนของหน้า

4. แสดงประโยชน์ของแอปเป็นข้อความสั้น 4 รายการ

## 9. มาตรฐาน QR Code

- สีโมดูลเป็นสีดำบนพื้นขาว
- ไม่วางโลโก้ทับกลาง QR Code
- ขนาด QR Code แต่ละรายการไม่น้อยกว่า 42 × 42 มิลลิเมตร
- มีพื้นที่ว่างรอบ QR Code อย่างน้อย 4 โมดูล
- ใช้ระดับแก้ไขข้อผิดพลาด M หรือสูงกว่า
- ทดสอบสแกนจากไฟล์ PDF และจากภาพถ่ายงานพิมพ์จำลอง
- แสดงชื่อปลายทางใต้ QR Code เสมอ เพื่อให้ผู้ใช้ทราบก่อนสแกน

## 10. หลักการอ่านง่ายและเข้าถึงได้

- ตัวอักษรเนื้อหาไม่เล็กกว่า 10.5 pt
- หัวเรื่องหลัก 28 ถึง 34 pt และหัวเรื่องรอง 18 ถึง 22 pt
- ใช้ระยะบรรทัดที่เหมาะกับภาษาไทย
- ไม่วางข้อความยาวบนภาพที่มีรายละเอียดมาก
- สีข้อความและพื้นหลังต้องมีความต่างชัดเจน
- ไม่ใช้สีเป็นวิธีสื่อความหมายเพียงอย่างเดียว
- ภาพหน้าจอต้องมีคำอธิบายประกอบสั้นและมองเห็นส่วนสำคัญได้จริง

## 11. เกณฑ์ตรวจรับ

ก่อนส่งมอบต้องตรวจครบทุกข้อ:

- เปิดไฟล์ Word และ PDF ได้โดยไม่มีข้อความหรือภาพหาย
- หน้าเอกสารเป็น A4 แนวตั้งจำนวน 2 หน้า
- ด้านหน้าและด้านหลังไม่ล้นพื้นที่ปลอดภัย
- ข้อความไม่มีคำผิดและใช้ภาษาธรรมชาติ
- QR Code ทั้ง 3 รายการสแกนได้และให้ข้อมูลตรงตามสเปก
- ภาพหน้าจอเป็นภาพจริงของ SciSiam และไม่ถูกยืดผิดสัดส่วน
- โลโก้และน้องไออุ่นคมชัด
- ตรวจภาพเรนเดอร์ด้านหน้าและด้านหลังที่ขนาดเต็มหน้า
- PDF เหมาะสำหรับพิมพ์หน้าและหลังโดยพลิกด้านตามขอบยาว
- ไม่มีการแก้ไขโค้ด แอป คู่มือ หรือรายงานเดิม
