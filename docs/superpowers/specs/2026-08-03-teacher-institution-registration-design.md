# การเลือกโรงเรียนและมหาวิทยาลัยในหน้าสมัครคุณครู

วันที่: 3 สิงหาคม 2569

## เป้าหมาย

หน้าสมัครสมาชิกสำหรับบทบาทคุณครูต้องแยกการค้นหาโรงเรียนกับมหาวิทยาลัยให้ชัดเจน ผู้สมัครเลือกประเภทสถานศึกษาก่อน แล้วค้นหาเฉพาะรายการในประเภทนั้น ระบบอนุมัติบทบาทคุณครูยังทำงานเหมือนเดิมและข้อมูลสถานศึกษาไม่มีผลต่อสิทธิ์ใช้งาน

## ข้อมูลมหาวิทยาลัย

ใช้รายชื่อจากไฟล์ `20251105003uni-2568.xlsx` ชีต `ข้อมูล ณ 12-12-2567` ซึ่งตรงกับชีต `สถาบันอุดมศึกษา`

- พบสถาบันอุดมศึกษา 195 แห่งและไม่มีชื่อซ้ำ
- นำเข้า 192 แห่งที่ยังเปิดดำเนินการ
- ไม่นำเข้า 3 แห่งที่ระบุว่าเลิกกิจการ
- ไม่นำเข้าชื่ออธิการบดี เพราะหน้าสมัครสมาชิกไม่ใช้ข้อมูลนี้

## โครงสร้างข้อมูล

เพิ่มคอลัมน์ `institution_type` ใน `public.school_catalog` โดยรับค่า `school` หรือ `university` และกำหนดค่าเริ่มต้นเป็น `school` เพื่อให้ข้อมูลโรงเรียนเดิมยังทำงานได้ทันที

ข้อมูลมหาวิทยาลัยใช้รหัสภายในที่สร้างจากชื่ออย่างคงที่ เก็บชื่อใน `name` เก็บกลุ่มสถาบันใน `school_type` และเก็บภาครัฐ เอกชน หรือนอกสังกัดใน `region` การค้นหาใช้ดัชนีร่วมของ `institution_type` และ `name`

ฟิลด์ `profiles.school_id` และ `profiles.school_name` ยังใช้เหมือนเดิมเพื่อรักษาความเข้ากันได้กับบัญชีเดิม ไม่เพิ่มสิทธิ์จาก metadata และไม่เปลี่ยนกระบวนการอนุมัติบทบาทคุณครู

## หน้าสมัครสมาชิก

เมื่อเลือกบทบาทคุณครู จะแสดงหัวข้อ `ประเภทสถานศึกษา` พร้อมตัวเลือกสองรายการ:

- `โรงเรียน`
- `มหาวิทยาลัย`

ช่องค้นหาเปลี่ยนป้ายกำกับ ตัวอย่าง และข้อความสถานะตามประเภทที่เลือก การเปลี่ยนประเภทจะล้างรายการที่เลือกไว้เพื่อป้องกันการส่งข้อมูลผิดประเภท ผลการค้นหามหาวิทยาลัยแสดงชื่อพร้อมประเภทสถาบันจากไฟล์ต้นทาง

ช่องค้นหายังใช้ label ถาวร รองรับคีย์บอร์ด และประกาศสถานะรายการผลลัพธ์ด้วยโครงสร้างเดิมของฟอร์ม

## การไหลของข้อมูล

1. ผู้สมัครเลือกบทบาทคุณครู
2. ผู้สมัครเลือกโรงเรียนหรือมหาวิทยาลัย
3. ฟอร์มค้นหา `school_catalog` โดยกรอง `institution_type`
4. ผู้สมัครเลือกรายการจากผลค้นหา
5. ระบบส่ง `school_id` และ `school_name` ไปกับคำขอสมัคร
6. Trigger ตรวจว่ารหัสมีอยู่จริงก่อนบันทึกลงโปรไฟล์
7. บัญชีใหม่ยังเป็นนักเรียนจนกว่าจะได้รับอนุมัติบทบาทคุณครู

## ข้อผิดพลาด

- ถ้ายังไม่ได้เลือกสถานศึกษา ให้ระบุว่าต้องเลือกโรงเรียนหรือมหาวิทยาลัยตามประเภทปัจจุบัน
- ถ้าโหลดรายการไม่สำเร็จ ให้บอกว่ารายชื่อสถานศึกษายังโหลดไม่ได้และให้ลองใหม่
- ถ้าค้นหาน้อยกว่า 2 ตัวอักษร จะยังไม่ส่งคำขอไปฐานข้อมูล
- ถ้าเปลี่ยนประเภทหลังเลือกรายการแล้ว ระบบจะล้างรายการเดิม
