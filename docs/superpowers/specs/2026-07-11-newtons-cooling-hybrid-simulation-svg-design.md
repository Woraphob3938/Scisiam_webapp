# Newton Cooling Hybrid Simulation SVG Design

## เป้าหมาย

ปรับเฉพาะ viewport ของแล็บ Newton's Law of Cooling ให้รู้สึกเป็น simulation ที่ตอบสนองต่อการทดลองจริงมากขึ้น โดยคงแบบจำลอง สมการ กราฟ แผงควบคุม การบันทึกผล และโครงสร้าง `SharedSimulationShell` เดิมทั้งหมด

## แนวทางภาพ

ใช้แนวทาง Hybrid Simulation: ชุดทดลองยังดูเหมือนอุปกรณ์ในห้องแล็บ แต่เพิ่มชั้นข้อมูลความร้อนที่ช่วยให้นักเรียนอ่านสถานะได้ทันที

- ขยายบีกเกอร์ เทอร์โมมิเตอร์ ขาตั้ง และเครื่องอ่านค่าให้เป็นจุดเด่นกลางฉาก
- เปลี่ยนพื้นหลังเป็น environmental chamber ที่นิ่งและเป็นระบบ ลดกริด จุดแสง และ glow ที่ไม่มีความหมาย
- แสดงพัดลมหรือช่องลมเป็นตัวแทนของอัตราการถ่ายเทความร้อน `k`
- ใช้ลูกศรความร้อนแสดงทิศทางจากวัตถุสู่สิ่งแวดล้อม หรือจากสิ่งแวดล้อมสู่วัตถุ
- ใช้เส้นการไหลเวียนภายในตัวอย่างแทนฟองอากาศ เพื่อไม่สื่อว่าของเหลวกำลังเดือด
- แสดงสถานะด้วยข้อความร่วมกับสี: `กำลังเย็นลง`, `กำลังอุ่นขึ้น`, `ใกล้สมดุล`

## การผูกกับแบบจำลอง

SVG ต้องรับค่าจาก state เดิมเท่านั้นและไม่สร้างกฎฟิสิกส์ชุดใหม่

- ผลต่างอุณหภูมิ: `deltaT = currentTemp - ambientTemp`
- ทิศทางความร้อน:
  - `deltaT > tolerance`: ความร้อนออกจากตัวอย่าง
  - `deltaT < -tolerance`: ความร้อนเข้าสู่ตัวอย่าง
  - `abs(deltaT) <= tolerance`: ใกล้สมดุล
- ความเด่นและความเร็วของการเคลื่อนไหวสัมพันธ์กับ `abs(deltaT) * coolingConstant`
- การเคลื่อนไหวหยุดเมื่อ simulation หยุด แต่ลูกศรและข้อความยังบอกทิศทางเชิงสถานะได้
- ฮีตเตอร์ยังใช้สถานะ `isHeaterOn` เดิม และต้องแยกจากการถ่ายเทความร้อนกับสิ่งแวดล้อมอย่างชัดเจน
- ไม่จำลองการเดือด การแข็งตัว หรือการเปลี่ยนสถานะ เพราะแบบจำลองปัจจุบันไม่ได้รวม latent heat

## องค์ประกอบ SVG

1. Environmental chamber: กรอบห้องทดลอง ช่องลม และพื้นโต๊ะที่ช่วยกำหนดบริบท
2. Apparatus: บีกเกอร์ตัวอย่าง เครื่องกวน/ฐานวาง เทอร์โมมิเตอร์ ขาตั้ง และจออ่านค่า
3. Thermal layer: ลูกศรความร้อนภายนอกและเส้น convection ภายในตัวอย่าง
4. Instrument state: จออุณหภูมิ แถบอุณหภูมิ และสถานะการทดลองที่อ่านได้โดยไม่พึ่งสีเพียงอย่างเดียว
5. Ambient indicator: แสดง `Tₛ` และลักษณะสภาพแวดล้อมอย่างกระชับภายในฉาก

## การเคลื่อนไหว

- ใช้ CSS/SVG animation ที่เบาและเปลี่ยนเฉพาะ `opacity`, `transform` หรือ `stroke-dashoffset`
- ไม่สร้าง animation loop ใน React และไม่เพิ่ม state ที่อัปเดตทุกเฟรม
- กำหนด animation 3 ระดับจาก heat-flow magnitude เพื่อลดการคำนวณและรักษาความนิ่ง
- รองรับ `prefers-reduced-motion`; เมื่อเปิดลดการเคลื่อนไหว ให้คงลูกศรและข้อความแบบ static

## Responsive และ Accessibility

- ใช้ `viewBox` เดียวและรักษาสัดส่วนอุปกรณ์บน desktop, tablet และ 390px
- overlay ต้องไม่ทับบีกเกอร์ จออ่านค่า หรือจุดที่เป็นสาระหลัก
- informative SVG ใช้ `<title>` และ `<desc>` ที่อัปเดตตามอุณหภูมิและทิศทางความร้อน
- decorative groups ใช้ `aria-hidden` โดยเนื้อหาสำคัญต้องมีข้อความ HTML/SVG ที่อ่านได้
- สถานะไม่สื่อด้วยแดง/น้ำเงินเพียงอย่างเดียว และคอนทราสต์ข้อความต้องผ่าน WCAG AA

## สิ่งที่ไม่เปลี่ยน

- สมการและการคำนวณ Newton cooling
- ช่วงค่า input และการรองรับค่าติดลบ
- กราฟ ตาราง บันทึกจุด และ Supabase experiment save
- layout ของ shared simulation shell และ simulation อื่น
- metadata, readiness registry และ route

## เกณฑ์ยอมรับ

- ทิศทางลูกศรถูกต้องทั้งกรณีตัวอย่างร้อนกว่าและเย็นกว่าสิ่งแวดล้อม
- สถานะใกล้สมดุลไม่แสดงการไหลแรงหรือทิศทางที่ทำให้เข้าใจผิด
- ไม่มีฟองหรือไอน้ำที่สื่อการเปลี่ยนสถานะโดยไม่มีแบบจำลองรองรับ
- SVG ไม่ใช้ definition id ซ้ำ และยังมี title/description ที่สัมพันธ์กับ state
- ไม่มี overflow หรือ control overlap ที่ความกว้าง 390px
- keyboard flow ของหน้าทดลองไม่เปลี่ยน และ reduced motion ปิดการเคลื่อนไหวตกแต่งได้
- `npm test`, `npm run lint` และ `npm run build` ผ่าน
