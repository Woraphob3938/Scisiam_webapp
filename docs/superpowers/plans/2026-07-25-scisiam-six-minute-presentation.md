# SciSiam Six-Minute Presentation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** จัดทำสคริปต์นำเสนอ SciSiam ภาษาไทย ความยาวประมาณ 6 นาที สำหรับผู้พูด 3 คน พร้อมคำกำกับภาพหรือวิดีโอ

**Architecture:** สคริปต์แบ่งตามบทบาทและเวลาที่ได้รับอนุมัติ โดยผู้พูดคนที่ 1 นำเสนอปัญหาและกลุ่มเป้าหมาย ผู้พูดคนที่ 2 อธิบายการใช้งานประกอบภาพ และผู้พูดคนที่ 3 อธิบายฐานข้อมูลกับความปลอดภัย ก่อนสรุปร่วม เนื้อหาฐานข้อมูลจะจัดเป็นหมวดเพื่อให้ครบถ้วนโดยไม่กลายเป็นการอ่านรายชื่อตาราง

**Tech Stack:** Markdown, ข้อมูลโครงการ SciSiam, นิยามฐานข้อมูล Supabase ใน `src/lib/supabase/database.types.ts`, PowerShell และ ripgrep สำหรับตรวจความครบถ้วน

## Global Constraints

- ระยะเวลารวมประมาณ 6 นาที
- มีผู้พูด 3 คนและมีประโยคส่งต่อระหว่างคน
- ใช้ภาพหน้าจอหรือวิดีโอประกอบ ไม่สาธิตระบบแบบสด
- เรียงเนื้อหาจากปัญหาและกลุ่มเป้าหมาย ไปสู่การใช้งาน ฐานข้อมูล และบทสรุป
- กล่าวถึงฐานข้อมูล 15 ตาราง พื้นที่จัดเก็บไฟล์ 3 ส่วน และระบบยืนยันตัวตน
- ใช้ภาษาพูดสุภาพ เป็นธรรมชาติ และไม่กล่าวอ้างเกินจริง
- ไม่กล่าวว่าคะแนนสะสมหรือค่าประสบการณ์เป็นคุณสมบัติที่เปิดใช้งาน
- ไม่เปิดเผยหรืออ้างว่าระบบเก็บข้อความสนทนา AI ทั้งหมด

---

### Task 1: เขียนบทผู้พูดคนที่ 1 และผู้พูดคนที่ 2

**Files:**
- Create: `output/doc/สคริปต์นำเสนอ_SciSiam_6นาที_3คน.md`
- Reference: `docs/superpowers/specs/2026-07-25-scisiam-six-minute-presentation-design.md`

**Interfaces:**
- Consumes: ช่วงเวลา 0:00 ถึง 3:35 นาทีและลำดับภาพที่ได้รับอนุมัติ
- Produces: บทเกริ่นปัญหา กลุ่มเป้าหมาย และบทอธิบายการใช้งานพร้อมคำกำกับภาพ

- [ ] **Step 1: สร้างหัวเอกสารและตารางเวลา**

ใส่ชื่อโครงการ ระยะเวลารวม รายชื่อบทบาทผู้พูด และตารางช่วงเวลา 0:00 ถึง 6:00 นาทีไว้ต้นเอกสาร

- [ ] **Step 2: เขียนบทผู้พูดคนที่ 1**

เขียนบทความยาวประมาณ 1 นาที 20 วินาที ครอบคลุมข้อจำกัดเรื่องอุปกรณ์ ค่าใช้จ่าย เวลา ความปลอดภัย ความเท่าเทียม กลุ่มเป้าหมาย และประโยคส่งต่อไปยังผู้พูดคนที่ 2

- [ ] **Step 3: เขียนบทผู้พูดคนที่ 2**

เขียนบทความยาวประมาณ 2 นาที 15 วินาที โดยวางคำกำกับภาพตามลำดับ สมัครหรือเข้าสู่ระบบ เลือกการทดลอง ค้นหาและกรอง อ่านรายละเอียด ปรับตัวแปร อ่านกราฟหรือตาราง บันทึกผล ใช้ AI ไออุ่น และใช้งานห้องเรียน

- [ ] **Step 4: ตรวจลำดับภาพ**

Run:

```powershell
rg -n "\[ภาพ|\[วิดีโอ" "output/doc/สคริปต์นำเสนอ_SciSiam_6นาที_3คน.md"
```

Expected: พบคำกำกับสื่อเรียงตามขั้นตอนการใช้งานตั้งแต่เข้าสู่ระบบจนถึงห้องเรียน

### Task 2: เขียนบทฐานข้อมูลและบทสรุป

**Files:**
- Modify: `output/doc/สคริปต์นำเสนอ_SciSiam_6นาที_3คน.md`
- Reference: `src/lib/supabase/database.types.ts`

**Interfaces:**
- Consumes: ประโยคส่งต่อจากผู้พูดคนที่ 2 และรายชื่อฐานข้อมูลที่ยืนยันจากโครงการ
- Produces: บทผู้พูดคนที่ 3 และบทสรุปร่วมจนถึงเวลา 6:00 นาที

- [ ] **Step 1: เขียนบทผู้พูดคนที่ 3**

อธิบาย Supabase Auth และฐานข้อมูลโดยแบ่งเป็นหมวดผู้ใช้และเนื้อหา หมวดการทดลอง หมวดห้องเรียน และหมวดระบบสนับสนุน กล่าวชื่อตารางครบ 15 ตาราง แต่เน้นหน้าที่และความเชื่อมโยงมากกว่าการอ่านรายละเอียดทุกฟิลด์

- [ ] **Step 2: อธิบายพื้นที่จัดเก็บไฟล์และความปลอดภัย**

กล่าวถึง `profile-avatars`, `classroom-files`, `experiment-snapshots`, การจำกัดสิทธิ์ตามผู้ใช้ สิทธิ์ของครูเจ้าของห้อง และการเก็บเฉพาะข้อมูลสถิติการใช้งาน AI ที่จำเป็น

- [ ] **Step 3: เขียนบทสรุปร่วม**

ให้ผู้พูดทั้งสามคนกล่าวคนละหนึ่งประโยคในช่วง 5:45 ถึง 6:00 นาที โดยสรุปเรื่องโอกาสในการทดลอง การสนับสนุนครู และการจัดการข้อมูล ก่อนกล่าวขอบคุณกรรมการ

- [ ] **Step 4: ตรวจว่าฐานข้อมูลครบ**

Run:

```powershell
$tables = @(
  'profiles','labs','school_catalog','experiment_runs','lab_progress',
  'classrooms','classroom_members','classroom_labs','classroom_assignments',
  'classroom_assignment_submissions','classroom_notifications',
  'mission_definitions','user_mission_progress','ai_usage_events','ai_rate_limits'
)
$text = Get-Content -Raw "output/doc/สคริปต์นำเสนอ_SciSiam_6นาที_3คน.md"
$tables | ForEach-Object { if ($text -notmatch [regex]::Escape($_)) { "MISSING: $_" } }
```

Expected: ไม่มีข้อความ `MISSING`

- [ ] **Step 5: ตรวจพื้นที่จัดเก็บไฟล์**

Run:

```powershell
rg -n "profile-avatars|classroom-files|experiment-snapshots" "output/doc/สคริปต์นำเสนอ_SciSiam_6นาที_3คน.md"
```

Expected: พบชื่อพื้นที่จัดเก็บไฟล์ครบทั้ง 3 ส่วน

### Task 3: ปรับภาษาและตรวจเวลา

**Files:**
- Modify: `output/doc/สคริปต์นำเสนอ_SciSiam_6นาที_3คน.md`

**Interfaces:**
- Consumes: สคริปต์ครบทั้ง 3 คนจาก Task 1 และ Task 2
- Produces: สคริปต์ฉบับพร้อมซ้อมและพร้อมนำเสนอ

- [ ] **Step 1: ปรับภาษาด้วย Humanizer**

แก้ประโยคให้เป็นภาษาพูดสุภาพ ลดประโยคซ้ำ ลดคำเชื่อมที่เป็นทางการเกินไป และคงชื่อระบบกับข้อเท็จจริงทุกส่วนไว้

- [ ] **Step 2: ตรวจจังหวะเปลี่ยนผู้พูด**

ตรวจว่าบทของผู้พูดคนที่ 1 และคนที่ 2 จบด้วยประโยคส่งต่อ ส่วนผู้พูดคนที่ 3 เชื่อมเข้าสู่บทสรุปร่วมโดยไม่หยุดกะทันหัน

- [ ] **Step 3: ตรวจความยาวเบื้องต้น**

Run:

```powershell
$text = Get-Content -Raw "output/doc/สคริปต์นำเสนอ_SciSiam_6นาที_3คน.md"
($text -replace '\[[^\]]+\]', '' -replace '`[^`]+`', '').Length
```

Expected: เนื้อหาบทพูดมีขนาดประมาณ 2,700 ถึง 3,400 ตัวอักษร โดยไม่นับคำกำกับภาพและชื่อเชิงเทคนิค

- [ ] **Step 4: ตรวจถ้อยคำต้องห้ามและข้อมูลสำคัญ**

Run:

```powershell
rg -n "คะแนนสะสม|ค่าประสบการณ์|เก็บข้อความสนทนาทั้งหมด|—|–" "output/doc/สคริปต์นำเสนอ_SciSiam_6นาที_3คน.md"
```

Expected: ไม่พบการอ้างว่าคะแนนสะสมหรือค่าประสบการณ์เปิดใช้งาน ไม่พบการอ้างว่าเก็บข้อความ AI ทั้งหมด และไม่พบเครื่องหมายขีดยาว

- [ ] **Step 5: ตรวจสคริปต์ด้วยการอ่านตามเวลา**

อ่านออกเสียงตามคำกำกับเวลาโดยใช้ความเร็วการนำเสนอปกติ หากช่วงใดเกินเวลา ให้ตัดคำอธิบายซ้ำก่อนตัดชื่อหมวดฐานข้อมูลหรือขั้นตอนการใช้งานที่กำหนดไว้ในสเปก

- [ ] **Step 6: บันทึกผล**

เก็บไฟล์ฉบับสมบูรณ์ไว้ที่ `output/doc/สคริปต์นำเสนอ_SciSiam_6นาที_3คน.md` และส่งมอบลิงก์ไฟล์พร้อมบทพูดฉบับเต็มในผลลัพธ์
